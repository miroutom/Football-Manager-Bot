# Чемпионат мира (ЧМ)

С сезона **4**, каждые **4** сезона (4, 8, 12…).

| | |
|---|---|
| Месяц | **11** (после финала ЛЧ в месяце 10) |
| БД | `db/season_N/world_cup.db` |
| Конфиг / нации | `data/world_cup_config.json` (48 сборных) |
| Заявки | `data/world_cup_squads.json` |
| Турнир / группы | `data/wc_tournament.json` |
| Формат | `utils/world_cup_format.py` |
| Календарь | `utils/wc_schedule.py` → `mixed_schedule.json` день 11 |
| Бот | `/wc` или кнопка «🌍 ЧМ» в меню |

## Формат (как FIFA WC 2026)

- **48** сборных → **12** групп (A–L) по **4**
- Жеребьёвка: **4 корзины × 12**, лимиты конфедераций в группе
- В группе каждый с каждым **один** раз
- В плей-офф: 1–2 места всех групп + **8 лучших третьих** → **1/16**
- Далее: 1/8 → 1/4 → 1/2 → матч за 3-е → финал

## Менеджеры

В `wc_tournament.json` → `managers.Roman` / `managers.Lika` — списки сборных (пришлёте позже). Пока заглушка.

## Вызовы

Меню ЧМ → «Вызовы»: сборная → игроки из `league.db` с той же `nation` → тап = в заявку / снять.

## Схемы сборных

Меню «⚽ Схема» → **ЧМ**, либо ЧМ → «⚽ Схемы сборных».
Состав берётся из `world_cup_squads.json` (вызовы); на PNG — **флаг нации**, не эмблема клуба.

## Награды

Автовыдачи нет. В сезоне ЧМ кнопки ЗМ/бутса/перчатка/boy в `/awards` открываются **после финала ЧМ** (ручной выбор).
