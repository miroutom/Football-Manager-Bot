# Чемпионат мира (бот)

Меню: **`/wc`** или **ЧМ** в главном меню.

## Заявка 26

Квота: **11 старт + 7 запас + 8 резерв = 26**, схема старта **4-3-3 ат**, **2 вратаря** (1 в старте, 1 в запасе/резерве).

Проверка: `utils/wc_squad_quota.py`.

## Вызовы и редактор заявки

**📣 Вызовы** → выбор сборной → список игроков из клубов и FA.

### Режимы внизу экрана

| Кнопка | Действие при тапе по игроку |
|--------|----------------------------|
| 🟢 Старт | В заявку / статус «старт» |
| 🟡 Запас | В заявку / «запас» |
| ⚪ Резерв | В заявку / «резерв» (по умолчанию) |
| ➖ Снять | Убрать из заявки |

**Повторный тап** по игроку **в том же режиме** — тоже снимает с заявки.

### Подписи строк

Формат: `имя · позиция · рейтинг` (и статус в «Заявка 26»).

Длинные / сложные имена (дефис, «Ди Мария», …) показываются **прозвищем** из `data/player_nicknames.json`, если оно задано (`scripts/assign_player_nicknames.py`).

### Заявка 26

Отдельный экран с теми же кнопками режима + **✅ Подтвердить заявку**, **🖼 Схема**, **✏️ Строками**.

Текстовый ввод строк (`WcEnter.squad_lines`):

```
Имя start [LW]
Имя bench
Имя reserve
```

Слоты старта: `LW ST RW LCM CAM RCM LB LCB RCB RB GK`.

## Данные

- Заявки: `data/world_cup_squads.json`
- Логика: `utils/wc_callups.py`, `bot/wc_handlers.py`
- PNG поля: `bot/squad_pitch.py` (`emblem_mode="nation"` для флагов)

## FA без клуба

**➕ Вне клубов** — ввод одной строкой: `Имя Позиция Рейтинг` (игрок попадает в `free_agents.db` и заявку).
