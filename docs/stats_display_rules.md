# Правила отображения статистики

Реализация: `utils/stats_history_agg.py`, пересборка `common` — `utils/common_db.py`,
голеадоры клуба — `player_stats.py`, накопление жёлтых к 4-й — `utils/player_discipline.py`.

## За всё время (топы, топ-100)

- Одна строка на игрока (имя + позиция), **сумма** матчей, голов, передач, карточек по всем
  архивным сезонам из `*_synced.db`.
- **Клуб** в таблице — команда из **активного** сезона (`season_state.json`), по строке
  с наибольшим `id` в `league.db` / `champions_league.db` / `common.db` активного снимка.

## Один сезон (архив `db/season_N/` или live)

### Национальная лига (РПЛ, АПЛ, …)

- Данные из `league.db`, только клубы этой лиги.
- Переход **между** лигами в одном сезоне → **две** строки в БД и в отчёте по каждой лиге
  (стата у старого клуба сохраняется).
- Несколько клубов **в одной** лиге за сезон → **одна** строка в отчёте: сумма голов/передач,
  клуб с max `id` (финальный клуб), пример: Наполи 1+0 и Милан 0+1 → 1+1 Милан.

### Лига чемпионов

- Всегда **одна** строка на игрока: сумма по всем клубам в ЛЧ за сезон, клуб последней
  записи в `champions_league.db` (max `id`).

### Все чемпионаты

- Из `common.db`: **полная** сумма нац. лиги + ЛЧ за сезон (например 2+2 в АПЛ, 0+1 в БЛ,
  1+1 в ЛЧ → **3+4**), клуб — запись с max `id` в common (текущий клуб сезона).

## Голеадоры по клубу

- Стата привязана к **клубу в строке БД**. После трансфера старая строка в клубе «откуда»
  не удаляется (`utils/player_transfer.py`).

## Карточки

| Что | Поведение |
|-----|-----------|
| `yellow_cards` / `red_cards` в SQLite | История за сезон/клуб; при трансфере **не** обнуляются |
| Накопление к 4-й жк (`yellow_cycle` в JSON) | ЛЧ — на игрока (не «залипает» на старом клубе); сброс нац. лиг при переходе **между** лигами |
| Новый сезон | Циклы жк в JSON сгорают; **дисквалы** с `matches_left > 0` переносятся; SQLite жк/кк остаются |

## Трансфер

- Новая строка в клубе «куда» с нулевой полевой статой; строка «откуда» со старой статой.
- Межлигой трансфер → сброс `yellow_cycle` только в нац. лигах (`include_cl=False`); цикл ЛЧ сохраняется.
